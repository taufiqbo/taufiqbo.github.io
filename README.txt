QUICK LOCAL PREVIEW (Windows PowerShell or Terminal)
1. Unzip the downloaded folder.
2. Open a terminal inside the taufiqbo.github.io folder.
3. Run: python -m http.server 8000
4. Open: http://localhost:8000
5. Press Ctrl+C in the terminal to stop.

If 'python' is not found on Windows, try: py -m http.server 8000

Everything needed for the site is in this folder: index.html, resume.pdf, and assets/.
Google Fonts load when internet access is available; system fonts are fallback.

GITHUB PAGES
1. Make GitHub repository: taufiqbo.github.io
2. Upload the CONTENTS of this folder (index.html, resume.pdf, assets), not the enclosing folder.
3. Settings > Pages > Deploy from branch > main > /(root) > Save.
4. Visit https://taufiqbo.github.io/
